# Hey Naheel Connect - Professional Landing Page

A minimal, high-end professional landing page and portfolio link hub for **Naheel J, Software Engineer**. Designed to serve as a central point for professional links, this project features an ultra-clean, Apple-esque light theme that prioritizes modern typography, subtle micro-animations, and a clutter-free enterprise-grade aesthetic.

## 🚀 Features

- **Ultra-Minimalist Design**: A clean, whitespace-driven layout tailored for a professional engineering brand.
- **Brand Personality**: Subtle brand colors integrated into interactive, color-coded cards (GitHub, LinkedIn, WhatsApp, Email, etc.).
- **Smooth Animations**: High-performance CSS transitions and staggered slide-up effects on page load.
- **Responsive Layout**: Perfectly scales from mobile devices to large desktop monitors.
- **Zero Heavy Dependencies**: Built entirely with Semantic HTML, modern CSS, and Vanilla JavaScript for maximum performance and minimal bloat.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript
- **Styling**: Vanilla CSS (No CSS frameworks)
- **Typography**: Google Fonts (Inter)
- **Icons**: Phosphor Icons
- **Hosting**: Firebase Hosting

## 📁 Project Structure

```text
├── css/
│   └── style.css       # Core styling, custom variables, and animations
├── js/
│   └── script.js       # Client-side logic and interaction handlers
├── index.html          # Main application structure

```

## ⚙️ Setup & Deployment

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NaheelJ/Hey.Naheel.connect.git
   ```

2. **Serve Locally:**
   You can serve the files using any static file server. For example:
   ```bash
   npx serve .
   ```
   Or using the Firebase CLI:
   ```bash
   firebase serve
   ```

3. **Deploy to Firebase:**
   Ensure you have the Firebase CLI installed and are authenticated (`firebase login`).
   ```bash
   firebase deploy --only hosting
   ```
